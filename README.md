# RePlate Campus

**Save Food. Save Money. Save Our Planet.**

RePlate Campus is a university food waste reduction web application aligned with **UN Sustainable Development Goal 12 (Responsible Consumption and Production)**. It connects university cafeterias and campus cafes with students so unsold meals can be listed at discounted prices before closing hours, reserved online, and collected at the counter with pickup verification.

---

## Project Objectives

1. Reduce daily edible food waste generated by university cafeterias and cafes.
2. Enable campus vendors to recover costs by selling surplus food at discounted prices.
3. Provide students with affordable campus meals.
4. Simplify ordering and counter collection via unique pickup codes and QR verification.
5. Track verified meals rescued and configurable environmental waste-reduction estimates.

---

## Technology Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Lucide React, QRCode
- **Backend & Database:** PostgreSQL via **Supabase** (Auth, Storage, Row Level Security, Triggers & Atomic RPCs) + Express full-stack API server (`server.ts`)
- **Optional AI Assistance:** Google `@google/genai` (`gemini-4-hydrogen`) server-side endpoint for drafting vendor food descriptions
- **Hosting & Deployment:** **Vercel** (`.vercel.app` & custom domains)

---

## Key Features

- **Three Role-Based Portals:**
  - **Student:** Register/login, browse & filter discounted meals, cart & Pay-at-Pickup checkout, QR + 6-character pickup codes, order tracking, order cancellation, vendor reviews, and personal rescue impact.
  - **Vendor:** Registration with administrator approval workflow, surplus food CRUD + image upload, automatic discount percentage calculation, incoming order status management, one-time pickup verification console, and sales reports.
  - **Administrator:** Vendor approval queue, student & vendor account suspension/activation, food category management, listing moderation, platform order monitoring, CSV report export, and configurable environmental estimate settings.

## Local Development Setup

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env` and fill in your credentials:
```bash
cp .env.example .env
```
- `VITE_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY` / `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY` (server-side only)
- `GEMINI_API_KEY` (optional, server-side only)

### 3. Run Locally
```bash
npm run dev
```
The application runs on `http://localhost:3000`.

### 4. Run Tests & Type Check
```bash
npm run test
npm run lint
npm run build
```
